## 高清呈现和动画取舍

- 图片继续使用原图纹理，不制作低分辨率主封面。反射专用的模糊采样保留。
- 队列边缘采用原始 .02 × 高清调节 .5 = .01，完整羽化带从 4% 减至 2%。这是视觉调节，不冒充原版常数。当前封面仍为 0。
- 队列切换保持 .7 秒，两个方向共用一条 cubic ease-out：`1 - (1-t)^3`，移除逐帧拟合引入的速度起伏。
- 下一首离场保留 .4 秒、向左、略缩小、淡出及底边约束；横移改为连续 smoothstep，不再穿过多个拟合节点。
- 上一首从左侧返回，与其它封面让位共用 .7 秒时钟和相同进度；只反转空间路径，不反转缓动时间。中途改方向从已显示的离场状态接续。
- 播放 / 暂停的 Front / Root 布局、水面大块波纹、倒影强度与队列终点保持当前实现。

验收限定为构建、现有行为检查、双向同步与速度连续性检查、一次浏览器操作抽查。视频采样误差仅报告，不再以三像素阈值驱动循环校准。

## 水波速度修正

原先将 60 个循环数据帧按 60 帧/秒播放，导致每秒重复一次。显示刷新率不能单独证明原版水波数据的推进频率。根据用户指出的过快问题，`PRESENTATION.waterLoopSeconds` 改为 **4 秒**，即之前的 **1/4 速度**；这是观感调节值，尚非确认的原版计时常数。相邻高度帧插值后再计算法线，慢放仍连续。数据、波幅、UV 扰动与倒影强度不变。
