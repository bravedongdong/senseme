- [用户指定的 PSP SensMe 实机教程，B2-66ER](https://www.bilibili.com/video/BV12qcnewEhZ/)，约 8 分钟之后；本轮动作和队列布局的主要参考。观察方法与选帧见 [reference-video.md](reference-video.md)。

- Official SensMe 1.50 installation package, preserved by Internet Archive: used for read-only inspection of metadata and plain numeric scene properties. Download provenance and hashes are in [original-package.md](original-package.md). - `public/reference/energetic.png` and `public/reference/shuffle-all.png` are local reconstruction assets decoded from Sony's original `bg.gim` resource. The source is the research-only `/tmp/sensme-reference/DATA.PSP.decrypted` ELF (`bg.gim` at file offset `0x1ba2c0`, resource span `0x264b20`, GIM SHA-256 `77313bd0858ce987e36e1c81ecfe22272c238ba158abfb776b3f476147fded4f`). `shuffle-all.png` is frame 5, image block relative offset `0xbfbf0`, block SHA-256 `eb9fbbc541ed7d55c95af5ef7fc68e863cb5cf67d02d0677738fa3f164e99c72`, output SHA-256 `e2e6ec8633a74d87e90a756ae77da94cb29fb673ff80deaa8b0958b24da51fe7`; `energetic.png` is frame 6, image block relative offset `0xe60a0`, block SHA-256 `6d183cc7ad9a733ee814ccb5d24f6ec4ee6e9ff77cf6a2157d30a3509e20fa11`, output SHA-256 `02a36654c851df478af2f0cd8d3e232edd63693186f4d9905a564864c06af4f9`. Both are 512×304 RGBA PNGs with pixels preserved after decoding. The original textures and associated SensMe marks are owned by Sony; these two files are retained only for this local reconstruction and are not a redistribution of the original program.
- [PlayStation Korean official blog, 11 January 2010](https://psblog.tistory.com/287): historical documentation; linked Flickr playback photos were unavailable.
- [SensMe channels on PPSSPP demonstration](https://www.youtube.com/watch?v=LkEoALPAYDo): identified as an animation reference; initial playback/download attempts failed; subsequently viewed in Chrome. It primarily demonstrates setup/menu navigation and is not evidence of matched song-transition timing.

## Water sequence

`public/water/sensme-height-75x65x65.s8.bin` contains the original numerical water height sequence: 316,875 signed-byte samples, extracted from the official SensMe 1.50 ELF at file offset `0x15f6f0`. SHA-256: `9b9ae52c3febb6323f27d39cc61aeb331f7424d4486fd75244672929756f7c57`. It contains data, not executable instructions. The source resource belongs to its original rights holder; the Three.js/GLSL implementation is independently written. Evidence and mathematical reconstruction are documented in [water-reverse.md](water-reverse.md).

## Demo music

Six 32-second synthesized ambient sketches, generated by `scripts/create-demo.py` for this project. Original note progressions and synthesis, no sampled recordings. These sketches are dedicated to the public domain under CC0. “SenseMe Sessions” is the demo collection name, not an external artist claim.
